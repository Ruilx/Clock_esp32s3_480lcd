# 4B 屏幕颜色自检

独立的 ESP-IDF 6.1 诊断工程。复用时钟的底层 LCD 驱动，但不链接 LVGL，不启动 Wi-Fi、NVS 或 RTC，不访问触摸。图案采用原始 RGB565 值，不在软件里换色；当前 ST7701 初始化省略官方表的 `0x21`，实际反相状态以色卡为准，Gamma 表保持原样。

在已激活 ESP-IDF 6.1 的 Windows PowerShell 中构建（不连接板也可以）：

```powershell
Set-Location 'D:\Project\Esp32-Waveshare'
idf.py -C diagnostics/lcd_color build
```

烧录会覆盖板上的部分出厂固件。事先确认 USB Serial/JTAG 对应的 COM 口、是否备份出厂 Flash，以及可以写入的目标。正常画面：上方从左到右 **红、绿、蓝、白**；下方从左到右 **黑到白，共 8 级灰阶**。灰阶只能目测有无反相、明显偏色或断阶，不能量化 Gamma。

- 上方若是蓝、绿、红、白，而下方仍由黑到白，说明当前链路的红蓝顺序与预期相反；先记录现象，不在自检里纠正。
- 若上方位置倒了，看下方灰阶方向以区分屏幕方向与单纯红蓝交换。
- 若黑白反转、亮着没内容、错行或重启，同时记录串口启动日志，不靠猜测改 Gamma 或位序。
